# Threat Intelligence Integration

## Objective
To integrate threat intelligence into Wazuh using AlienVault OTX, enrich alerts with IOC data, and perform threat hunting based on MITRE ATT&CK techniques.

---

## Tools Used
- Wazuh (SIEM)
- AlienVault OTX (Threat Intelligence)
- TheHive (Conceptual IR workflow)

---

## Lab Environment
- Wazuh Server: 192.168.1.10  
- Windows Agent: 192.168.1.3  
- Agent Name: Addytesting1  

---

## Activities Performed

1. Imported AlienVault reputation feed into Wazuh as a CDB list.
2. Added mock IOC (192.168.1.100) into the feed.
3. Created a custom Wazuh rule to detect matching IPs.
4. Generated a test event using JSON log.
5. Observed alert triggered in Wazuh dashboard.
6. Performed threat hunting for login activity (T1078).
7. Analyzed authentication logs.

---

## Threat Feed Import

AlienVault OTX reputation data was imported into Wazuh using a CDB list.  
A mock IP (192.168.1.100) was inserted into the feed to simulate a malicious indicator.

## Threat Hunting (T1078 - Valid Accounts)

### Query Used

data.win.system.eventID:4624

---

### Observations

- Multiple successful login events detected
- Event ID: 4624 (Windows logon success)
- Agent: Addytesting1
- Activity generated by non-system users

### Interpretation

The presence of multiple successful logins indicates active user sessions.  
Such activity is important for detecting misuse of valid credentials.

---

## Threat Hunting Summary 

Threat hunting for MITRE ATT&CK technique T1078 identified multiple successful login events (Event ID 4624) from non-system accounts. While no confirmed malicious activity was observed, the analysis demonstrates how valid account usage can be monitored to detect unauthorized access, credential misuse, and potential lateral movement within the system.

## Conclusion

Threat intelligence integration significantly improves detection capabilities in Wazuh.  
By correlating alerts with external IOC feeds, enriched context is achieved.

Threat hunting complements this by identifying suspicious behavior such as valid account misuse, even when no direct IOC match exists.
